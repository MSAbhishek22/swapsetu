# Project Design Registry — SwapSetu 3D vs the three most recent projects

| | SwapSetu 3D (this) | Night Touge | TriageMate | PolyGlance |
|---|---|---|---|---|
| Metaphor | Planner's model table / diorama | A windscreen at 2 a.m. | A triage desk (paper, stamps) | Smart-glasses display face |
| Theme | Light, warm paper | Dark blue night | Light editorial | True-size 576×288 device UI |
| Accent | Battery green | Amber sodium | Editorial red/blue ink | Live-odds green/red |
| Display type | Georgia serif masthead | Monospace instruments | Serif headlines | Device sans |
| Layout | Broadsheet → model table → ledger | Full-screen game + screens | Desk with columns | Glasses pane + browser sim |
| 3D treatment | Orbitable daylight city diorama, sim-driven | First-person endless road | None (2D) | None (text display lines) |
| Interaction model | Point at the model; place towers | Drive with keys | Sort/filter a desk | Voice + chips |
| Motion | Quiet fades, eased camera | Speed, FOV kick, streaks | Minimal | Minimal |

Conclusion: SwapSetu changes metaphor, palette direction, typography,
layout, interaction model and 3D treatment versus all three. It reuses
only engineering utilities (vendored Three.js r160, the CDP smoke-test
pattern), not any visual template.
